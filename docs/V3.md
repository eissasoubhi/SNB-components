# SNB-components v3

SNB-components v3 is a deliberately small shared core for the Summernote Bricks ecosystem.

## Scope

The package contains only primitives that are useful across more than one brick:

- semantic/versioned brick metadata helpers;
- DOM lookup and parsing helpers;
- narrow Summernote context integration helpers;
- history-safe DOM mutation helpers.

It is **not** a UI framework and does not own brick-specific dialogs, rendering, validation, source loading or lifecycle.

## Runtime contract

- native DOM;
- no React/Vue runtime;
- no direct Bootstrap dependency;
- no jQuery or Summernote runtime dependency bundled into the package;
- consumers pass the Summernote context only where an operation needs it.

Because the core does not import jQuery or Summernote at runtime, the v3 candidate intentionally has no host peer dependencies. Concrete plugins such as Heading and Gallery declare their own jQuery/Summernote peer ranges.

## Distribution

The v3 release candidate is staged as `3.0.0-rc.0` with:

- ESM: `dist/index.js`;
- UMD/CommonJS-compatible browser artifact: `dist/index.umd.cjs`;
- TypeScript declarations: `dist/types/index.d.ts`;
- package `exports` for import/require/types;
- only distribution files and public documentation included in the npm package.

The historical root package remains unchanged until the v3 ecosystem gates are complete.

## Compatibility policy

The shared core itself is browser-library code and does not claim Summernote interface compatibility independently. Summernote compatibility is proven by the concrete Heading/Gallery and Bricks composition Playwright matrices.

Breaking changes to exported metadata schemas or helpers require a major version after v3 becomes stable.
